# 🟩 종료코드  

### 🟡 종료코드의 의미  

| 종료 코드 | 일반적인 의미 | 설명 |  
|---:|---|---|
| `0` | ✅ 성공 | 정상적으로 프로그램 종료 |  
| `1` | ❌ 일반 오류 | 가장 흔한 일반적인 실패 |  
| `2` | ❌ 사용법/인자 오류 | 잘못된 명령행 인자 등 |  
| `126` | ❌ 실행 불가 | 명령어는 존재하지만 실행할 수 없음 |  
| `127` | ❌ 명령어 없음 | command not found |  
| `128` | ❌ 비정상 종료 관련 | 보통 시그널 종료 계산의 기준값 |  
| `130` | ❌ `Ctrl+C` | `SIGINT(2)` → `128 + 2 = 130` |  
| `137` | ❌ 강제 종료 | `SIGKILL(9)` → `128 + 9 = 137` |  
| `143` | ❌ 종료 요청 | `SIGTERM(15)` → `128 + 15 = 143` |  
| `255` | ❌ 특수/비정상 오류 | 프로그램별 의미가 다름 |
